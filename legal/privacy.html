ปรับปรุงล่าสุด: {{UPDATED}}

Code Quest ({{SITE}}) เป็นเกมเรียนเขียนโปรแกรมภาษาไทย นโยบายนี้อธิบายว่าเราเก็บข้อมูลอะไร ใช้อย่างไร และคุณมีสิทธิ์อะไรบ้าง เราไม่ขายข้อมูลส่วนบุคคล ไม่แสดงโฆษณา และไม่ใช้คุกกี้ติดตามเพื่อการตลาด

1. ข้อมูลที่เราเก็บ

เมื่อสมัครด้วยอีเมล

  • อีเมล และชื่อที่แสดง (ตั้งเอง)
  • รหัสผ่าน — เก็บเฉพาะค่าที่ผ่านการเข้ารหัสทางเดียว (bcrypt) เราไม่เห็นรหัสผ่านจริงของคุณ
  • สถานะการยืนยันอีเมล และรหัสยืนยันชั่วคราว (เก็บแบบเข้ารหัส และลบทิ้งหลังใช้)

เมื่อเข้าสู่ระบบด้วย Google

  • อีเมล ชื่อ และรหัสประจำบัญชี Google (Google ID) ที่ Google ส่งมาหลังคุณยินยอม
  • เราไม่ได้รับรหัสผ่าน Google รายชื่อติดต่อ ไฟล์ หรือข้อมูลอื่นในบัญชี Google ของคุณ และไม่เก็บ token ของ Google

ข้อมูลการเรียนและการเล่น

  • ภารกิจที่ผ่านแล้ว EXP เลเวล ตัวละครหรือรูปประจำตัวที่คุณเลือก
  • เมื่อเข้าห้องแข่งขัน: ชื่อที่ใช้ในห้อง คะแนน และข้อที่ทำได้
  • โค้ดหรือคำตอบที่ส่งตรวจ ใช้เพื่อตรวจคำตอบในขณะนั้นเท่านั้น ไม่ได้บันทึกเก็บไว้

โหมดผู้เยี่ยมชม

ถ้าเล่นโดยไม่สมัคร ความคืบหน้าและโค้ดที่บันทึกอัตโนมัติจะเก็บในเบราว์เซอร์ของคุณเท่านั้น (localStorage) ไม่ถูกส่งมาที่เซิร์ฟเวอร์ จนกว่าคุณจะเลือกนำเข้าบัญชีตอนสมัคร

2. คุกกี้และการจัดเก็บในเบราว์เซอร์

  • คุกกี้เข้าสู่ระบบ — จำว่าคุณล็อกอินอยู่ (อายุสูงสุด 30 วัน) ตั้งค่าแบบ HttpOnly และส่งผ่าน HTTPS เท่านั้น เซิร์ฟเวอร์บันทึกชนิดเบราว์เซอร์และระบบปฏิบัติการ (user agent) ของแต่ละอุปกรณ์ เพื่อแสดงรายการอุปกรณ์ในหน้าตั้งค่า — ไม่บันทึกหมายเลข IP หรือตำแหน่ง
  • คุกกี้ชั่วคราวระหว่างเข้าสู่ระบบด้วย Google — ใช้ป้องกันการปลอมคำขอ หมดอายุภายใน 15 นาที
  • localStorage — เก็บการตั้งค่า (เช่น เปิด/ปิดเสียง) ภาษาที่เรียนล่าสุด ความคืบหน้าของผู้เยี่ยมชม และโค้ดที่บันทึกอัตโนมัติ

3. เราใช้ข้อมูลเพื่อ

  • สร้างและดูแลบัญชี ให้คุณเล่นต่อได้ทุกอุปกรณ์
  • ตรวจคำตอบ คำนวณ EXP และจัดตารางอันดับ
  • ส่งอีเมลยืนยันตัวตน (ไม่ส่งอีเมลโฆษณา)
  • ป้องกันการโกง การเดารหัสผ่าน และการใช้งานในทางที่ผิด

4. ข้อมูลที่ผู้อื่นมองเห็น

ตารางอันดับและห้องแข่งขันแสดงชื่อที่แสดง เลเวล EXP และตัวละครของคุณให้ผู้เล่นคนอื่นเห็น ไม่แสดงอีเมล แนะนำให้ใช้ชื่อเล่นแทนชื่อจริง

5. ผู้ให้บริการที่เกี่ยวข้อง

เราใช้บริการต่อไปนี้เพื่อให้เว็บทำงานได้ ซึ่งอาจได้รับข้อมูลทางเทคนิค เช่น หมายเลข IP ตามการทำงานปกติของอินเทอร์เน็ต

  • Railway — โฮสต์เว็บไซต์และฐานข้อมูล
  • Google — เข้าสู่ระบบด้วย Google (เฉพาะเมื่อคุณเลือก) และแบบอักษร Google Fonts
  • Resend — ส่งอีเมลยืนยันตัวตน
  • jsDelivr — ดาวน์โหลดตัวรันภาษา Python ให้ทำงานในเบราว์เซอร์ของคุณ

เราไม่ส่งต่อข้อมูลให้บุคคลอื่นเพื่อการตลาด และจะเปิดเผยเฉพาะเมื่อกฎหมายกำหนดเท่านั้น

6. การเก็บรักษาและความปลอดภัย

เราเก็บข้อมูลบัญชีไว้จนกว่าคุณจะลบบัญชีในหน้าตั้งค่าหรือขอให้เราลบ ข้อมูลถูกส่งผ่าน HTTPS รหัสผ่านและรหัสยืนยันถูกเข้ารหัส และมีระบบจำกัดการเข้าสู่ระบบผิดซ้ำๆ อย่างไรก็ตาม ไม่มีระบบใดปลอดภัยได้ 100% หากพบปัญหาด้านความปลอดภัย กรุณาแจ้งเราตามช่องทางด้านล่าง

7. สิทธิ์ของคุณ

ในหน้า ตั้งค่า คุณทำได้เอง: แก้ไขชื่อ ตัวละคร และรหัสผ่าน · ดาวน์โหลดสำเนาข้อมูลของคุณ (ไฟล์ JSON) · ออกจากระบบอุปกรณ์อื่น · ซ่อนชื่อจากตารางอันดับ · และลบบัญชีถาวร (ลบบัญชี ความคืบหน้า และการตั้งค่าทันที ชื่อในประวัติห้องแข่งจะเปลี่ยนเป็น “ผู้เล่นที่ลบบัญชี”) หากต้องการความช่วยเหลือเพิ่มเติม ติดต่อตามอีเมลด้านล่าง

8. ผู้ใช้ที่เป็นเด็กและนักเรียน

ผู้ใช้จำนวนมากเป็นนักเรียน ผู้ใช้อายุน้อยควรใช้งานภายใต้การดูแลของผู้ปกครองหรือครู และสามารถเล่นในโหมดผู้เยี่ยมชมได้โดยไม่ต้องให้ข้อมูลส่วนบุคคลใดๆ หากผู้ปกครองต้องการให้ลบบัญชีของบุตรหลาน ติดต่อเราได้ตามอีเมลด้านล่าง

9. การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลงที่สำคัญ เราจะปรับวันที่ด้านบนและแจ้งให้ทราบบนเว็บไซต์
