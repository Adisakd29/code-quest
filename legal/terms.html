ข้อกำหนดการใช้งาน

ปรับปรุงล่าสุด: {{UPDATED}}

การใช้งาน Code Quest ({{SITE}}) ถือว่าคุณยอมรับข้อกำหนดนี้และนโยบายความเป็นส่วนตัว

1. บริการ

Code Quest เป็นเกมเรียนเขียนโปรแกรมเพื่อการศึกษา ใช้งานได้ฟรี ทั้งแบบผู้เยี่ยมชมและแบบมีบัญชี เราอาจปรับปรุง เพิ่ม หรือเปลี่ยนแปลงเนื้อหาและฟีเจอร์ได้ตามความเหมาะสม

2. บัญชีผู้ใช้

  • ใช้อีเมลที่เป็นของคุณจริง และเก็บรักษารหัสผ่านไว้เป็นความลับ
  • หนึ่งคนควรมีหนึ่งบัญชี
  • คุณรับผิดชอบกิจกรรมที่เกิดขึ้นในบัญชีของคุณ หากสงสัยว่ามีผู้อื่นเข้าใช้ ให้เปลี่ยนรหัสผ่านและแจ้งเรา

3. การใช้งานที่ไม่อนุญาต

  • ตั้งชื่อที่แสดงหรือชื่อห้องที่หยาบคาย ดูหมิ่น หรือแอบอ้างเป็นผู้อื่น
  • โกงคะแนน EXP หรือผลการแข่งขัน เช่น ใช้โปรแกรมอัตโนมัติ หรือส่งคำขอปลอมไปยังระบบ
  • พยายามเจาะระบบ เข้าถึงบัญชีผู้อื่น หรือทำให้บริการใช้งานไม่ได้
  • ใช้บริการในทางที่ผิดกฎหมาย

หากพบการใช้งานที่ไม่อนุญาต เราอาจลบคะแนน ซ่อนชื่อจากตารางอันดับ หรือระงับบัญชีได้

4. เนื้อหา

บทเรียน โจทย์ และภาพประกอบใน Code Quest ใช้เพื่อการเรียนรู้ส่วนบุคคลและในชั้นเรียนได้ ครูนำไปใช้สอนได้ โค้ดที่คุณเขียนเป็นของคุณ โลโก้ภาษาโปรแกรมเป็นเครื่องหมายการค้าของเจ้าของแต่ละราย

5. ข้อจำกัดความรับผิด

บริการนี้ให้ใช้ “ตามสภาพ” เราพยายามให้เนื้อหาถูกต้องและระบบทำงานต่อเนื่อง แต่ไม่รับประกันว่าจะไม่มีข้อผิดพลาดหรือหยุดชะงัก และไม่รับผิดชอบต่อความเสียหายที่เกิดจากการใช้งาน เท่าที่กฎหมายอนุญาต

6. การยกเลิก

คุณหยุดใช้งานหรือขอลบบัญชีได้ทุกเมื่อ โดยติดต่อตามอีเมลด้านล่าง

7. การเปลี่ยนแปลงข้อกำหนด

หากมีการเปลี่ยนแปลงที่สำคัญ เราจะปรับวันที่ด้านบนและแจ้งให้ทราบบนเว็บไซต์ การใช้งานต่อหลังการเปลี่ยนแปลงถือว่ายอมรับข้อกำหนดใหม่
